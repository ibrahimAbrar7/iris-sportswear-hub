# IRIS Sport Style

IRIS — PREMIUM SPORT-SPECIFIC CLOTHING & SPORTS FASHION E-COMMERCE WEBSITE

MASTER WEBSITE DESIGN & DEVELOPMENT PROMPT

Design and develop a premium, modern, high-converting, production-ready e-commerce website for IRIS, positioned as a sports clothing and athletic fashion destination for the USA market.

The website should take inspiration from the category architecture, filtering, sport discovery, merchandising and shopping experience of major sports-fashion retailers such as Champs Sports, while having a completely original IRIS visual identity, layout, content and branding.

Reference for UX/category inspiration:

https://www.champssports.com/

DO NOT CLONE CHAMPS SPORTS.

Create an original premium sports-fashion experience.

1. MOST IMPORTANT BRAND DIRECTION

IRIS must be positioned primarily as:

SPORTS CLOTHING + PERFORMANCE APPAREL + ATHLETIC FASHION + SPORTS ACCESSORIES

The website should NOT feel like:

A sneaker store

A footwear-first retailer

A generic fashion boutique

A basic Shopify template

A general clothing store

The overwhelming visual emphasis must be on:

CLOTHING. CLOTHING. CLOTHING.

Shoes should exist, but they should be a secondary category.

Recommended merchandising balance:

70–80% Clothing

15–20% Accessories

5–10% Footwear

Do not allow shoes to dominate the homepage.
